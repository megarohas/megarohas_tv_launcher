# Mega TV Launcher

[English](README.md) | **Русский**

Минималистичный лаунчер для Android TV в стиле Apple TV. Чистый Kotlin + RecyclerView — без Leanback-библиотеки и лишнего веса.

## Возможности

- **Главный экран в духе tvOS** — сетка баннеров 16:9 с плавным увеличением в фокусе, тёмный градиентный фон
- **Свечение фокуса** — мягкое гало в доминантном цвете обложки приложения под выбранной карточкой
- **Ручная перестановка** — удержите OK на карточке → *Переместить*, двигайте стрелками, OK — сохранить
- **Папка скрытых приложений** — удержите OK → *Скрыть*; внутри папки нажатие запускает приложение, удержание OK возвращает его на главный экран
- **Плавное растворение рядов** — при прокрутке ряды тают у верхней кромки и выплывают из-за нижней
- **Перехват кнопки HOME** — встроенный сервис специальных возможностей поднимает лаунчер поверх стокового Google TV; никакие системные пакеты не отключаются
- **Часы и дата**, кнопка системных **настроек**, меню по удержанию OK (Скрыть / О приложении / Удалить)
- Список обновляется сам при установке и удалении приложений; интерфейс на русском и английском

## Установка (компьютер не нужен)

1. Скачайте `mega-tv-launcher.apk` из [релизов](../../releases) прямо на приставку — например,
   приложением **Downloader**, через **LocalSend** или любой файловый менеджер. Разрешите
   установку из неизвестных источников, когда система спросит.
2. Установите APK и откройте *Mega TV Launcher* из списка приложений — лаунчер сразу работает.

### Как сделать его домашним экраном

**Обычный Android TV (AOSP-приставки, Fire TV, старые прошивки):** нажмите HOME — система
предложит выбрать лаунчер, либо задайте его в *Настройки → Приложения → Приложения по умолчанию →
Главный экран*.

**Google TV (Chromecast с Google TV, приставки Xiaomi на Google TV и т.п.):** прошивка жёстко
навязывает стоковый лаунчер, поэтому используйте встроенный перехват кнопки HOME:

1. Откройте *Настройки → Система → Специальные возможности → Mega TV Launcher* и включите сервис.
2. На Android 13+ переключатель может быть заблокирован предупреждением «Настройка с ограниченным
   доступом» для приложений, установленных не из магазина. Тогда сначала откройте *Настройки →
   Приложения → Mega TV Launcher*, выберите **Разрешить ограниченные настройки** (в меню ⋮),
   после чего включите сервис ещё раз.
3. Нажмите HOME — стоковый экран мелькнёт на долю секунды, и поверх встанет Mega TV Launcher.
   Всё полностью обратимо: выключите сервис специальных возможностей — и вернётся сток.

### Через adb (необязательно, для продвинутых)

```
adb install mega-tv-launcher.apk
adb shell cmd package set-home-activity tv.megarohas.launcher/.MainActivity
adb shell cmd role add-role-holder --user 0 android.app.role.HOME tv.megarohas.launcher
```

На Google TV двух команд выше недостаточно (стоковый лаунчер объявляет HOME-фильтр с
`priority=2` и всегда побеждает) — вместо этого включите перехват:

```
adb shell settings get secure enabled_accessibility_services
adb shell settings put secure enabled_accessibility_services "<прежнее значение>:tv.megarohas.launcher/.HomeWatchService"
adb shell settings put secure accessibility_enabled 1
```

> **Внимание:** не отключайте стоковый лаунчер
> (`pm disable-user com.google.android.apps.tv.launcherx`), хотя большинство гайдов советуют
> именно это. Он — запасной вариант при загрузке: если его отключить, падение или медленный старт
> стороннего лаунчера оставит приставку на чёрном экране, где сетевой ADB ещё не поднялся.
> Перехват выше существует ровно для того, чтобы этого никогда не делать.

## Сборка

JDK 17 + Android SDK (API 34):

```
gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Требования

Android TV 5.0+ (minSdk 21, target 34). Проверено на приставке Xiaomi с Android 14 (Google TV).
